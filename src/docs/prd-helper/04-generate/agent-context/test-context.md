## 测试边界

1. **固定点 vs 区域点** — 固定点必须恰好 1 个点，区域点必须≥2 个点
2. **检测项周期不一致** — 与设备不一致时保存提示确认
3. **启用状态切换** — 开启显示全部字段，关闭隐藏配置项
4. **跨区域调度** — 优先区域无空闲时才触发
5. **图片预览** — 所有图片点击可放大，无 JS 报错

## 异常场景

- 地图画框超出地图边界
- 校准坐标获取超时
- 调度规则配置冲突
- 检测项周期配置冲突
- 机器人状态异常（离线/故障）

## 回归影响

每次改动需回归：
- 路由切换和系统切换
- 表单校验和保存
- 列表筛选和排序
- 图片预览功能
- 构建通过
