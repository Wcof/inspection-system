# 项目总览

## 1. 项目背景

本项目为**安全生产巡检机器人管理系统**，面向工业环境中的自主巡检机器人，提供从地图建模、点位配置、设备绑定、调度规则到巡检任务执行、异常处理、结果统计的全链路管理能力。

系统最初为单体 Web 后台，混合承载运行态、业务态、构建态三类问题。经多次迭代，已拆分为**管理端**（`/management/*`）和**实施平台**（`/implementation/*`）两套可切换界面，并通过 GitHub Pages 部署。

**来源**: background.md §1-2; session-codex-019d673f Turn 3-6

## 2. 业务目标

系统最终让机器人明确三件事：
1. **应该怎么走** — 通过地图建模、途径点、路径网络、巡检路线规划
2. **走到哪些巡检点** — 通过巡检点标记（固定点/区域点）
3. **到达每个巡检点后检查什么** — 通过设施设备绑定、检测项配置、云台坐标

在此基础上，支持周期性巡检计划，由计划定时生成任务，驱动机器人自动执行。

**来源**: session-codex-019d4cd9 Turn 1

## 3. 角色与系统归属

| 角色 | 使用系统 | 核心职责 |
|------|---------|---------|
| 运维人员 | 实施平台 | 地图建模、途径点维护、巡检路线规划 |
| 实施工程师 | 实施平台 | 点位配置、设备绑定、检测项设置、校准 |
| 客户/运营方 | 管理端 | 巡检计划排布、任务管理、异常追踪、调度决策 |
| 领导/管理者 | 驾驶舱 | 实时运行监控、告警查看、统计报表 |

**来源**: background.md §4

## 4. 系统范围

### 管理端（`/management/*`）
- 总调度台、巡检计划、巡检任务、异常中心、巡检统计

### 实施平台（`/implementation/*`）
- 地图管理（列表/编辑/区域管理/点位管理）
- 机器人管理（列表/详情）
- 点位与设备管理（巡检点/设施设备/检测项）
- 调度配置（规则/资源/通知/边巡边检）
- 校准记录（隐藏，保留待以后使用）

### 驾驶舱（独立项目 `drive-dashboard`）
- 实时运行监控、告警查看、对象建模链路展示

### 公共能力
- 全局图片预览（AppLayout.vue）

**来源**: decisions.md decision_001; page-map.md

## 5. 核心业务流程

```
构图 → 途径点维护 → 路径网络连接 → 巡检路线规划 → 巡检点标记 → 二次校对
                                                          ↓
                                          设施设备绑定 → 检测项配置 → 云台坐标
                                                          ↓
                                          巡检计划 → 任务生成 → 执行 → 告警 → 证据
```

**来源**: session-codex-019d4cd9 Turn 1; session-codex-019e3dfb Turn 2

## 6. 关键约束

1. **方案约束优先** — 实施改造方案中的约束和禁止事项具有最高优先级
2. **弱模型实施保护** — 方案必须包含充分的历史背景、边界判断原则、禁止事项
3. **不改功能只改样式** — 用户要求"只动 CSS"时严格只做样式层调整
4. **提交前 commit 保护** — 多步改动前先提交当前状态，便于回滚
5. **不合并到 main** — 日常开发只 push 当前分支，版本发布时合并
6. **检测项字段一致性** — 采集向导与检测对象弹窗必须完全一致

**来源**: constraints.md
