# 规则关联

## rule_001 — 计划调度生成任务
- **规则说明**: 巡检计划按配置周期（周/月/一次性）定时生成巡检任务实例
- **来源事实**: fact_002
- **触发功能**: feature_001（巡检计划管理）
- **关联数据**: data_001（InspectionPlan）, data_003（InspectionTask）
- **关联验收**: acc_001（计划生成任务验证）

## rule_002 — 异常升级流程

- **关联数据**: data_005（ExceptionLog）, data_006（Alert）
- **关联验收**: acc_002（异常升级通知验证）

## rule_003 — 检查周期配置
