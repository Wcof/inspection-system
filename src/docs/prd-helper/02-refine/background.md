# 业务背景

## 1. 背景摘要

本项目为**安全生产巡检机器人管理系统**，面向工业环境中的自主巡检机器人，提供从地图建模、点位配置、设备绑定、调度规则到巡检任务执行、异常处理、结果统计的全链路管理能力。系统分为**管理端**（业务运营与调度决策）和**实施平台**（系统构建与校准配置）两套可切换界面。

## 2. 业务现状

- 系统最初为单体 Web 后台，混合承载运行态（机器人实时状态）、业务态（计划/任务/调度）、构建态（地图/点位/设备/校准）三类问题
- 已通过多次迭代拆分为双系统架构：`管理端`（`/management/*`）和 `实施平台`（`/implementation/*`）
- 管理端调度台已整合为统一控制台，任务管理新增执行轨迹/检查结果/复盘子页面
- 实施平台调度配置页面已合并（DispatchRule→DispatchRuleConfig，ResourceStrategy→ResourceBaseConfig）
- 检测规则状态已跨页面统一
- 数据层无真实后端，全部通过 `localStorage` + `MockService` 模拟
- 已部署 GitHub Pages，支持在线访问

**来源**: `session-codex-019d673f` Turn 3-6, `session-codex-019d4cd9` Turn 1, commit 5ce0c97, commit e7ff351
