# 安全生产巡检任务管理系统设计文档

## 1. 系统架构概述

安全生产巡检任务管理系统是一个基于 Vue 3 + TypeScript 开发的智能巡检系统，主要用于管理机器人、巡检点、设施设备以及巡检计划。系统通过机器人进行环境构图、标记巡检点、执行巡检任务，实现自动化的安全生产巡检。

## 2. 核心流程

### 2.1 机器人构图与巡检点标记流程

1. **首次构图**：
   - 机器人在指定区域内自主移动，构建环境地图
   - 系统记录机器人的移动路径和环境数据

2. **巡检点标记**：
   - 在构建好的地图上，人工或自动标记需要巡检的关键点
   - 每个巡检点包含名称、位置坐标、描述等基本信息
   - 标记时可设置巡检点的重要程度（是否为关键巡检点）

3. **二次校对**：
   - 机器人按照标记的巡检点路径再次运行
   - 对每个巡检点进行精确定位和校对
   - 确保巡检点位置的准确性

### 2.2 设施设备管理流程

1. **关联设施设备**：
   - 在每个巡检点下关联需要检查的设施设备
   - 每个设施设备包含名称、类型、编码等基本信息

2. **设备坐标数据**：
   - 存储设施设备相对于云台的 X 轴、Y 轴坐标数据
   - 确保机器人到达巡检点后能够准确对准设备

3. **设备图片数据**：
   - 存储设施设备的参考图片
   - 用于机器人视觉识别和比对

4. **设备监测指标**：
   - 为每个设施设备设置需要监测的指标（如温度、压力、电压等）
   - 定义每个指标的正常范围和阈值

### 2.3 巡检计划与任务执行流程

1. **创建巡检计划**：
   - 选择执行巡检的机器人
   - 选择巡检的路线和途径的巡检点
   - 设置计划的执行周期（周执行或月执行）
   - 配置计划的开始时间、结束时间等参数

2. **任务生成**：
   - 系统根据巡检计划的设置，定时生成巡检任务
   - 每个任务包含具体的执行时间、机器人、巡检点等信息

3. **任务执行**：
   - 任务到达执行时间后，系统安排机器人执行
   - 机器人按照预设路线前往各个巡检点
   - 在每个巡检点，机器人根据存储的坐标数据对准设施设备
   - 采集设备数据并与参考图片进行比对
   - 记录巡检结果和异常情况

4. **任务完成**：
   - 机器人完成所有巡检点的检查后返回基站
   - 系统生成巡检报告，记录巡检结果和异常情况
   - 如有异常，系统发送通知提醒相关人员

## 3. 数据结构设计

### 3.1 巡检点 (InspectionPoint)

```typescript
interface InspectionPoint {
  id: string;              // 巡检点ID
  name: string;            // 巡检点名称
  code: string;            // 巡检点编码
  description: string;     // 巡检点描述
  location: {
    longitude: number;     // 经度
    latitude: number;      // 纬度
    altitude?: number;     // 海拔高度
  };
  facilityDeviceId?: string; // 关联的设施设备ID
  monitorPoints: MonitorPoint[]; // 监测点列表
  isCritical: boolean;     // 是否为关键巡检点
  exceptionStrategy: InspectionPointExceptionStrategy; // 异常处理策略
  createdAt: Date;         // 创建时间
  updatedAt: Date;         // 更新时间
}
```

### 3.2 监测点 (MonitorPoint)

```typescript
interface MonitorPoint {
  id: string;              // 监测点ID
  name: string;            // 监测点名称
  code: string;            // 监测点编码
  inspectionPointId: string; // 所属巡检点ID
  deviceType: string;      // 设备类型
  metrics: Metric[];       // 监测指标列表
  position?: {
    x: number;             // 云台X轴坐标
    y: number;             // 云台Y轴坐标
    z: number;             // 云台Z轴坐标
  };
  stayDuration: number;    // 停留时间
  createdAt: Date;         // 创建时间
  updatedAt: Date;         // 更新时间
}
```

### 3.3 监测指标 (Metric)

```typescript
interface Metric {
  id: string;              // 指标ID
  name: string;            // 指标名称
  code: string;            // 指标编码
  unit: string;            // 单位
  threshold: {
    min?: number;          // 最小值
    max?: number;          // 最大值
    warning?: number;      // 警告阈值
    critical?: number;     // 临界阈值
  };
  monitorPointId: string;  // 所属监测点ID
  createdAt: Date;         // 创建时间
  updatedAt: Date;         // 更新时间
}
```

### 3.4 巡检计划 (InspectionPlan)

```typescript
interface InspectionPlan {
  id: string;              // 计划ID
  name: string;            // 计划名称
  code: string;            // 计划编码
  robotId: string;         // 执行计划的机器人ID
  status: InspectionPlanStatus; // 计划状态
  type: InspectionTaskType; // 任务类型
  inspectionPointIds: string[]; // 巡检点ID列表
  inspectionPoints?: InspectionPoint[]; // 巡检点列表
  path?: InspectionPath;   // 巡检路径
  schedule: {
    startTime: Date;       // 开始时间
    endTime?: Date;        // 结束时间
    repeatInterval?: number; // 重复间隔
    repeatUnit?: 'minute' | 'hour' | 'day' | 'week'; // 重复单位
  };
  config: {
    autoStart: boolean;    // 是否自动开始
    notifyOnComplete: boolean; // 完成时通知
    notifyOnError: boolean; // 错误时通知
    autoResumeAfterInterrupt: boolean; // 中断后自动恢复
  };
  exceptionStrategy: TaskExceptionStrategy; // 异常处理策略
  createdAt: Date;         // 创建时间
  updatedAt: Date;         // 更新时间
}
```

### 3.5 巡检任务实例 (InspectionTaskInstance)

```typescript
interface InspectionTaskInstance {
  id: string;              // 任务实例ID
  planId: string;          // 所属计划ID
  plan?: InspectionPlan;   // 所属计划
  name: string;            // 任务名称
  code: string;            // 任务编码
  robotId: string;         // 执行任务的机器人ID
  status: InspectionTaskInstanceStatus; // 任务状态
  inspectionPointIds: string[]; // 巡检点ID列表
  inspectionPoints?: InspectionPoint[]; // 巡检点列表
  path?: InspectionPath;   // 巡检路径
  currentInspectionPointIndex: number; // 当前巡检点索引
  progress: number;        // 任务进度
  exceptionLog: ExceptionLog[]; // 异常日志
  startedAt?: Date;        // 开始时间
  completedAt?: Date;      // 完成时间
  createdAt: Date;         // 创建时间
  updatedAt: Date;         // 更新时间
}
```

## 4. 系统功能模块

### 4.1 机器人管理

- **机器人列表**：展示所有机器人的基本信息，包括名称、序列号、型号、状态、电量等
- **机器人详情**：查看机器人的详细信息，包括基本信息、异常策略、连接配置等
- **机器人编辑**：创建和编辑机器人，设置基本信息、电池阈值、连接配置、异常策略等

### 4.2 巡检点管理

- **巡检点列表**：展示所有巡检点的基本信息，包括名称、编码、位置、状态等
- **巡检点详情**：查看巡检点的详细信息，包括基本信息、关联的设施设备、监测点等
- **巡检点编辑**：创建和编辑巡检点，设置基本信息、位置、关联的设施设备、异常策略等

### 4.3 设施设备管理

- **设备列表**：展示所有设施设备的基本信息，包括名称、类型、编码、状态等
- **设备详情**：查看设备的详细信息，包括基本信息、关联的巡检点、监测指标等
- **设备编辑**：创建和编辑设备，设置基本信息、关联的巡检点、监测指标等

### 4.4 巡检计划管理

- **计划列表**：展示所有巡检计划的基本信息，包括名称、编码、执行周期、状态等
- **计划详情**：查看计划的详细信息，包括基本信息、执行机器人、巡检点、执行周期等
- **计划编辑**：创建和编辑计划，设置基本信息、执行机器人、巡检点、执行周期等

### 4.5 任务管理

- **任务列表**：展示所有巡检任务的基本信息，包括名称、编码、状态、执行时间等
- **任务详情**：查看任务的详细信息，包括基本信息、执行机器人、巡检点、执行状态等
- **任务执行**：手动触发任务执行，监控任务执行状态

### 4.6 异常管理

- **异常日志**：展示所有巡检过程中的异常情况，包括异常类型、发生时间、处理状态等
- **异常详情**：查看异常的详细信息，包括异常类型、发生位置、处理建议等
- **异常处理**：对异常进行处理，记录处理结果

## 5. 技术实现要点

### 5.1 机器人构图与定位

- 使用 SLAM (Simultaneous Localization and Mapping) 技术实现机器人自主构图
- 通过激光雷达、摄像头等传感器获取环境数据
- 构建高精度的环境地图，为巡检点标记和机器人导航提供基础

### 5.2 巡检点标记与校对

- 在构建好的地图上，通过 UI 界面手动标记巡检点
- 支持拖拽、缩放等操作，精确定位巡检点位置
- 机器人二次运行时，对标记的巡检点进行自动校对，确保位置准确性

### 5.3 设施设备坐标与图片管理

- 机器人到达巡检点后，通过云台控制对准设施设备
- 记录设施设备相对于云台的 X 轴、Y 轴坐标
- 拍摄设施设备的参考图片，用于后续的视觉识别和比对
- 建立设备坐标和图片的关联数据库，方便查询和管理

### 5.4 巡检计划与任务调度

- 基于 cron 表达式或类似机制实现巡检计划的定时调度
- 支持周执行、月执行等多种执行周期
- 任务调度系统根据计划设置，自动生成巡检任务
- 任务执行时，实时监控机器人状态和巡检进度

### 5.5 异常处理与通知

- 建立异常检测机制，及时发现巡检过程中的异常情况
- 根据预设的异常策略，自动处理常见异常
- 对于严重异常，及时发送通知提醒相关人员
- 建立异常日志系统，记录异常发生的时间、位置、类型等信息

## 6. 系统界面设计

### 6.1 布局结构

- 左侧菜单：包含设施设备管理、智能巡检等主菜单
- 顶部标题栏：显示系统名称和当前页面标题
- 内容区域：显示当前页面内容，包括列表、表单、详情等

### 6.2 主要页面

- **机器人管理页面**：展示机器人列表，支持添加、编辑、删除机器人
- **巡检点管理页面**：展示巡检点列表，支持添加、编辑、删除巡检点
- **设备设施页面**：展示设备设施列表，支持添加、编辑、删除设备设施
- **巡检计划页面**：展示巡检计划列表，支持添加、编辑、删除巡检计划
- **巡检统计页面**：展示巡检相关的统计信息，包括巡检次数、异常数量等
- **异常日志页面**：展示巡检过程中的异常情况，支持查看异常详情和处理状态

## 7. 系统集成与扩展

### 7.1 与机器人控制系统集成

- 通过 WebSocket 或其他通信协议与机器人控制系统进行实时通信
- 发送控制指令，接收机器人状态和传感器数据
- 实现对机器人的远程监控和控制

### 7.2 与其他系统集成

- 与企业资源管理系统 (ERP) 集成，获取设备信息和维护记录
- 与监控系统集成，获取视频监控和环境监测数据
- 与告警系统集成，实现异常情况的及时通知

### 7.3 系统扩展

- 支持添加新的机器人类型和品牌
- 支持添加新的设备类型和监测指标
- 支持自定义巡检计划和异常处理策略
- 支持添加新的报表和统计功能

## 8. 总结

安全生产巡检任务管理系统通过机器人自主构图、标记巡检点、执行巡检任务，实现了自动化的安全生产巡检。系统不仅提高了巡检效率和准确性，还减少了人工巡检的工作量和风险。通过对巡检点和设施设备的精细管理，以及对巡检计划和任务的智能调度，系统为企业的安全生产提供了有力的保障。

未来，系统可以进一步扩展，引入人工智能技术，实现更智能的异常检测和预测性维护，为企业的安全生产管理提供更全面的支持。
