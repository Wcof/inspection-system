# 业务背景

## 1. 背景摘要

本项目是面向化工/工业场景的安全生产巡检机器人管理平台，用于管理自主巡检机器人的地图建模、点位配置、设备管理、任务调度、异常处理和结果分析。系统当前处于 POC 验证阶段，数据基于 localStorage mock，无真实后端。

## 2. 业务现状

- 系统已从单体后台拆分为管理端和实施端双系统架构
- 管理端负责日常调度、任务执行、异常处理和报表统计
- 实施端负责地图建模、点位配置、设备绑定、检测项设置
- 独立的 Dashboard 指挥中心大屏面向领导层，展示全局态势
- 当前所有数据为 mock 数据，无真实后端 API
- 项目使用 GitHub Pages 静态部署，支持 v1/v2 双版本

## 3. 当前痛点

- **概念边界不清**：巡检点、停车点、执行点概念混淆，数据模型不规范
- **检测能力缺乏复用**：检测项配置与具体设施绑定，无法跨设施复用
- **菜单结构混乱**：单体后台混合了运行态、业务态、构建态功能
- **Dashboard 需求反复**：指挥中心大屏的信息架构经历大量调整，边界不清晰
- **字段命名不统一**：如"调度类型"vs"周期类型"、"区域"vs"分区"
- **操作流程不合理**：部分页面跳转目标错误、删除缺乏关联影响提示
- **告警交互反复**：证据切换功能反复出现 bug 未彻底解决

## 4. 相关角色

| 角色 | 关注点 |
|------|--------|
| 领导/管理层 | 全局态势感知、安全可控、巡检价值展示、汇总数据、风险热点 |
| 领班/现场管理人员 | 任务执行进度、巡检效果、机器人状态、异常处理 |
| 实施人员（乙方） | 地图建模、点位配置、设备绑定、检测项设置、校准回写 |
| 操作员 | 任务调度、临时任务创建、异常确认处置 |
| 开发团队 | POC 阶段快速迭代，通过 Codex agent 辅助开发 |
