# 业务约束清单

## constraint_001：双系统切换限制

- 约束内容：不允许再出现第三个系统切换项（只允许管理端和实施平台）
- 约束类型：业务
- 影响对象：顶部切换器、全局路由
- 违反后果：系统结构混乱，职责边界不清
- 来源材料：session-codex-019d673f (Turn 7)
- 来源位置：架构约束讨论
- 状态：已确认

## constraint_002：驾驶舱冻结

- 约束内容：不允许把驾驶舱混进本轮顶部切换器，不允许把dashboard纳入本轮主导航结构
- 约束类型：范围
- 影响对象：Dashboard、顶部切换器
- 违反后果：改造范围过大，无法聚焦
