# 业务目标

## goal_001：系统架构拆分

- 目标内容：将单体后台拆分为管理端和实施平台两套可切换系统，实现职责边界清晰分离
- 目标类型：业务
- 影响对象：全局路由、菜单结构、所有页面
- 来源材料：session-codex-019d673f (Turn 6-7)
- 衡量方式：管理端和实施端菜单独立，无功能交叉，路由前缀隔离
- 状态：已确认

## goal_002：建立五层业务模型

- 目标内容：建立五层业务模型（空间执行、被检对象、检测能力、任务执行、结果闭环），使系统适配化工巡检机器人业务
- 目标类型：业务
- 影响对象：全局数据模型、所有业务模块
- 来源材料：session-codex-019d673f (Turn 21)
- 衡量方式：数据模型覆盖五层，实体关系清晰
- 状态：已确认

## goal_003：构建可追溯任务执行链路

- 目标内容：构建可追溯的任务执行链路：计划→任务快照→采集动作→检测结果→异常闭环→证据链

- 影响对象：巡检计划、任务管理、异常中心
