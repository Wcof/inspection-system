### User Query

新增检测规则中的结果分类里面业务结果和采集质量结果有什么区别？


### Agent Answer

业务结果和采集质量结果的区别是：

**业务结果**
表示“这次检测已经有效完成，并且得出了业务判断”。

例如：

- 正常
- 预警
- 告警
- 严重告警
- 阀门开
- 阀门关
- 压力异常
- 温度异常
- 气体超标
- 人员违规

它回答的是：

```text
被检测对象到底有没有问题？
```

**采集质量结果**
表示“这次采集本身有问题，导致不能可靠判断业务状态”。

例如：

- 无法读取
- 被遮挡
- 模糊
- 反光
- 目标缺失
- 视角不足
- 未到达
- 采集失败

它回答的是：

```text
这次采集的数据能不能用于判断？
```

**关键区别**

| 对比项 | 业务结果 | 采集质量结果 |
|---|---|---|
| 判断对象 | 被检对象本身 | 本次采集过程/数据质量 |
| 是否形成业务结论 | 是 | 否 |
| 是否算有效覆盖 | 一般算 | 一般不算 |
| 是否可生成异常 | 可以 | 可以，但异常类型应是不可检/采集失败/监测失效 |
| 示例 | 温度告警、气体超标、阀门异常 | 图片模糊、反光、目标缺失、无法读取 |

**举例**

热成像检测电机：

- `正常`：业务结果，说明电机温度正常。
- `告警`：业务结果，说明电机温度异常。
- `图像模糊`：采集质量结果，说明热成像数据质量不够，不能判断电机是否异常。

压力表识别：

- `读数正常`：业务结果。
- `读数超限`：业务结果。
- `反光无法读取`：采集质量结果。

所以这里建议保留两个分类，因为它们后续会影响：

- 覆盖率统计
- 是否需要补检
- 异常类型归属
- 人工复核逻辑
- 任务结果是否算有效完成
