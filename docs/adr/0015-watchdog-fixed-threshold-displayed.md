# ADR 0015 — 看门狗时效锁阈值固定外显、触发动作挂路段

**状态**：已确认
**日期**：2026-06-23
**关联模块**：7月迭代 模块四（运行策略与路网底座 — 物理安全双向锁/看门狗时效锁）

## 背景

清单模块四要求"执行层引入通信看门狗。若网络抖动导致车端在 0.3~0.4 秒内未收到云端控制或调度台心跳，强制车机端 Fallback 为自动降速或紧急停车"。

现状：机器人配置有心跳间隔（30 秒）和超时（10 秒），但这是"云端检测机器人离线"方向，不是清单说的"车端检测云端心跳丢失"的反向看门狗。ADR 0014 已定路段级心跳频率（100~10000ms），看门狗阈值与路段心跳频率直接相关。

## 决策

**看门狗阈值固定 0.3~0.4 秒，不允许用户配置，但必须在页面上外显展示**。触发动作（降速/紧急停车）挂路段级配置。

**阈值展示**：路段详情/编辑页只读展示看门狗阈值（0.3~0.4 秒），不可编辑。

**路段新增字段**：

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| 看门狗阈值 | 数字 | 固定 300~400ms，只读外显 | 车端未收到云端心跳超过此阈值即 fallback |
| 看门狗触发动作 | 枚举 | `decelerate`（降速）/ `emergency_stop`（紧急停车） | fallback 动作，默认紧急停车 |

**mock 方式**：调度台加"模拟网络抖动"按钮，点击后 mock 丢失心跳 → 车端按路段配置的触发动作 fallback → 调度台留痕展示。

## 理由

- 清单明确写 0.3~0.4 秒是固定阈值，是工业安全标准值不该让用户乱改
- 阈值外显保证操作员知情，但不可改避免误配导致安全事故
- 触发动作与路况强相关——窄道便桥该紧急停车、主干道降速即可，归路段合理

## 后果

- 路网管理页的路段详情/编辑页新增看门狗阈值（只读）和触发动作（可配）展示
- 调度台新增"模拟网络抖动"按钮用于 mock 触发
- 调度台记录看门狗 fallback 事件留痕
- 与 ADR 0014 路段心跳频率联动：路段心跳频率配 200ms 时，丢 1~2 个心跳即触发 fallback

## 相关

- 取决于：ADR 0014（路段级心跳频率，与阈值联动）
- 影响：调度台新增模拟按钮、路段字段扩展
