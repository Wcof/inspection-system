# ADR 0005 — 自动派车选车规则归属调度规则配置页

**状态**：已确认
**日期**：2026-06-23
**关联模块**：7月迭代 模块二（调度引擎与任务中心）

## 背景

计划解耦机器人后（ADR 0004），"自动派车"的选车规则需要确定归属。候选位置：
- 各计划自己配（散落）
- 调度规则配置页统一配（清单模块二"疲劳段频次与优先级控制"也是改这个页）

## 决策

选车规则统一挂**调度规则配置页**，不散落到各计划。

## 理由

- 清单模块二已在动调度规则配置页（加时间段调度矩阵），选车规则天然属于调度规则的一部分
- 选车逻辑散落各计划会与"动态抢占式 DAG"冲突——抢占时下一个任务给哪台车必须由全局调度规则统一裁决
- 计划只声明"做什么"，调度规则页负责"谁来做、什么时候做"

## 后果

- 调度引擎算派车时按全局调度规则统一裁决
- 抢占场景下的选车也走调度规则页，不回头看计划局部配置
- 与资源基础配置页的职责边界另见 ADR 0006

## 相关

- 取决于：ADR 0004（计划解耦机器人）
- 影响：ADR 0006（资源基础配置页 vs 调度规则配置页边界）
