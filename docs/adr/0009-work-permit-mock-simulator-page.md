# ADR 0009 — 作业票模拟方案与第三方系统模拟页

**状态**：已确认
**日期**：2026-06-23
**关联模块**：7月迭代 模块二（调度引擎与任务中心 — 动态作业票系统对接）

## 背景

清单模块二要求"提供 WorkPermitService 模拟接口。当外部动火、受限空间等特种作业开票时，调度系统接收作业参数并拆分为机器人的'临时最高优先级'区域监护任务（DAG 强插挂起日常巡检）"。

现状：作业票在 `src/` 零实现，仅在历史会话文档里作为"任务来源=作业票"字段口径出现，明确写过"作业票只做页面字段和 mock 数据，不做真实接口"。

项目定位为**原型系统**，所有数据 mock，无真实外部 EHS 系统可对接。

## 决策

建一个**"第三方系统"模拟页**，页面内提供触发按钮。点击一次按钮代表第三方系统推送了一条作业票数据，后续联动（拆为监护任务、DAG 强插挂起日常巡检）在原型内闭环。

**模拟页定位**：
- 不是业务页面，是"外部系统模拟器"
- 每种外部推送类型（作业票/第三方任务/EHS 告警等）一个触发按钮
- 点击即生成 mock 推送数据，驱动本系统联动逻辑

**作业票联动闭环**：
- 点击"推送作业票"按钮 → 生成 mock 作业票数据（含作业类型/区域/时段/监护要求）
- 调度引擎接收 → 拆为"临时最高优先级区域监护任务"
- 按 ADR 0007：作业票监护属自动抢占场景，强插挂起当前日常巡检
- 任务来源=作业票，业务场景=作业票监护
- 作业结束后关票（模拟器再点一次按钮或任务完成自动关票）

## 理由

- 原型系统无真实外部系统可对接，模拟页是最直接的 mock 方式
- 比内置完整作业票 CRUD 页更轻量，聚焦调度联动而非作业票本身管理
- 模拟页可复用于其他第三方推送场景（第三方任务、EHS 告警推送等），一处建好长期受益
- 与项目既有定位一致（localStorage mock、无真实后端）

## 后果

- 新增"第三方系统"模拟页，路由放**系统设置**菜单下（原型系统页面不按实施/管理端物理分割，通过菜单管理区分）
- 模拟页提供多种推送触发按钮（作业票/第三方任务/EHS 告警等，按需扩展）
- WorkPermitService 作为 mock 服务，接收模拟页推送并驱动调度引擎
- 作业票数据结构需定义（作业类型/区域/时段/监护要求/关联人员等）
- 联动调度引擎、抢占逻辑（ADR 0007）、任务状态机（ADR 0008）

## 相关

- 取决于：ADR 0003（任务统一）、ADR 0007（抢占分级——作业票监护自动抢占）、ADR 0008（任务状态机）
- 影响：后续第三方任务/EHS 告警推送 mock 可复用第三方系统模拟页
