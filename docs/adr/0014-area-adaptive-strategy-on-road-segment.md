# ADR 0014 — 区域/路况环境自适应策略归路段级

**状态**：已确认
**日期**：2026-06-23
**关联模块**：7月迭代 模块四（运行策略与路网底座 — 区域/路况环境自适应策略）

## 背景

清单模块四要求"策略从机器人级解耦。机器人驶入不同边缘区域时，前端模拟下发不同 ROS2 参数——主干道全速/正常心跳；装置区降速/短心跳；窄道便桥极低速/高频心跳+语音提醒"。

现状：
- 心跳间隔挂机器人配置（heartbeatInterval=30秒），机器人级
- 限速已挂路段（ADR 0001 确认）
- 语音提醒不存在
- 安全等级刚在 ADR 0012 标记为路段新增字段

## 决策

三项运行策略（限速/心跳频率/语音提醒）**都归路网管理页的路段编辑**，从机器人级解耦到路段级。

**路段新增字段**：

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| 限速 | 数字 | 已有，km/h | 路段最大允许速度 |
| 心跳频率 | 数字 | 100~10000ms，默认沿用机器人配置 | 机器人行经该路段时的心跳间隔（值越小越频繁）；配置时校验不高于机型心跳上限 |
| 语音提醒 | 枚举 | `none`/`approaching_hazard`/`narrow_road`/`restricted_area`，默认 none | 行经该路段时播报的语音类型 |
| 语音提醒内容 | 字符串 | 可选，默认按枚举类型自动生成 | 自定义语音播报内容 |

**机器人配置的处理**：机器人配置里现有的 heartbeatInterval 作为"默认值"——路段未配置心跳频率时用机器人默认值；路段配置了则路段值覆盖机器人默认。

## 理由

- 清单明确"驶入不同区域时下发不同 ROS2 参数"，触发条件是路段，策略就该跟着路段走
- 心跳频率虽受机器人硬件能力限制，但"在该路段要多少频率"是路段策略，机器人硬件上限只是配置校验项（校验频率不低于机型下限即可）
- 把心跳留机器人级会违背"解耦"目标
- 按区域分组不够细——同区域不同路段策略可能不同（如主干道 vs 装置区同属一区但策略不同），必须路段级

## 后果

- 路网管理页的路段编辑表单新增"心跳频率""语音提醒""语音提醒内容"字段
- 限速字段已有，无需新增
- 机器人配置的 heartbeatInterval 保留为默认值，路段配置覆盖
- 执行端 mock：机器人行经路段时读取路段策略 mock 下发不同参数

## 相关

- 取决于：ADR 0001（路网为拓扑底座）、ADR 0012（路段级配置模式）
- 影响：模块四"看门狗时效锁"（心跳频率与此联动）、机器人配置默认值保留
