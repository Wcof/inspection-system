# ADR 0003 — 任务对象统一为单一类型

**状态**：已确认
**日期**：2026-06-23
**关联模块**：7月迭代 模块二（调度引擎与任务中心）

## 背景

7月迭代功能清单模块二要求"巡检任务重构，执行时间和反馈结果下沉至 Task 承载，由 Plan 动态派生 Task 实例"。

现状并存两个相似任务类型：
- 任务（InspectionTask）：字段较重，含执行时间/反馈/优先级/异常日志/任务来源枚举
- 计划派生实例（InspectionTaskInstance）：字段是任务的严格子集，无独立存在价值

## 决策

合并为一个任务对象。废弃"计划派生实例"，统一用"任务"，按"任务来源"字段区分是计划派生的还是临时派发的。

## 理由

- 任务已有"任务来源"枚举（计划派生/调度插入/自动复核/作业票/第三方/紧急/手动），足够区分来源
- 计划派生实例的字段是任务的严格子集，无独立存在价值
- 合并后调度引擎只面对一种任务对象，DAG 抢占逻辑更简单

## 后果

- 任务的"所属计划"字段改为可空（临时任务不挂计划）
- 计划派生任务时写入"任务来源=计划派生"
- 报表/历史功能若单独依赖"计划派生实例"，改为按"任务来源"过滤
- 影响面：所有引用"计划派生实例"的地方都要迁移
