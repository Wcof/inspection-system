# ADR 0013 — 边巡边检执行端联动落调度台

**状态**：已确认
**日期**：2026-06-23
**关联模块**：7月迭代 模块三（边巡边检 — 执行端联动）

## 背景

清单模块三执行端联动三条：
1. 24帧/秒抽帧识别流控制
2. 云台空旷区避空保护
3. 漫游异常即时锚定

现状：执行端联动在 `src/` 零实现。原型无真实边缘 GPU，三条均需 mock。清单原文"页面不等待任务结束，即时在当前坐标生成漫游异常临时锚点"暗示需一个"执行中"实时页面承载。

现状执行中实时页面有二：调度台（任务执行监控主界面，含实时遥测和告警）、控制台（单机器人远控视角，含视频流/云台控制）。

## 决策

**三条执行端联动 mock 均落调度台**，不新建自由巡检执行监控页。

1. **24帧/秒抽帧识别流**：调度台任务执行中，按路段云台扫描策略（ADR 0012）mock 生成抽帧识别结果流，在任务卡片/地图上展示识别进度与命中项
2. **云台空旷区避空保护**：执行 mock 时按 ADR 0012 俯仰角上限 +30° 约束自动避空，避空事件在调度台留痕
3. **漫游异常即时锚定**：行进中识别到温升/气味变动等，即时在调度台地图上生成"漫游异常临时锚点"，不等待任务结束

**展示区分**：调度台靠"巡检模式"字段（定点/区域/自由）区分展示形态，不新建页面。

## 理由

- 调度台已是任务执行监控主界面，实时遥测和告警天然落此
- 控制台聚焦远控操控，非告警主场
- 自由巡检与定点巡检共用调度台监控，靠巡检模式字段区分，避免页面膨胀
- 原型阶段 mock 识别流即可，无需真实边缘 GPU

## 后果

- 调度台新增自由巡检模式下的展示形态：实时抽帧识别流 + 漫游异常锚点
- 调度台地图新增"漫游异常临时锚点"图层
- Mock 服务按路段云台扫描策略生成抽帧识别结果流
- 避空事件留痕到调度台记录

## 相关

- 取决于：ADR 0012（路段级云台扫描策略，提供 mock 数据源）
- 影响：调度台展示形态扩展、ADR 0010 漫游异常锚点走异常处置流程
