# ADR 0021 — 大模型增强作为检测规则兜底配置

**状态**：已确认
**日期**：2026-06-23
**关联模块**：7月迭代 模块六（AI智能平台对接 — 多模态非标隐患解释结论）

## 背景

清单模块六要求"在结果证据页，当传统算法无法框选非标隐患时，调用多模态大模型，展示结构化解释、总结与规则引用来源"。

现状：检测规则的视觉映射有 recognitionMode（template/ocr/ai）单算法，无大模型兜底。结果页有"复核结论"列但无大模型解释。

用户澄清领域语义：大模型应作为检测规则的**兜底算法**，不是结果页的独立解释区块。创建单条检测规则时新增"大模型增强"开关，开启后主算法识别失败时由大模型兜底。主要针对图片和视频相关算法。

## 决策

**检测规则新增"大模型增强"字段（是否用大模型兜底），规则级配置**。

**配置**：
- 检测规则表单新增"大模型增强"开关字段，默认关闭
- 开启后，该规则主算法识别失败时由大模型兜底处理

**结果展示**：
- 大模型兜底返回的结果**按正常算法识别结果格式返回**，对结果展示透明
- 仅在结果的"备注"字段显示"大模型增强"标识来源
- 不单独建"大模型解释"区块，不展示结构化解释/总结/规则引用来源（清单原文的展示方式取消）

## 理由

- 大模型下沉为规则的兜底能力，比结果页独立解释更符合领域语义——兜底是规则配置的一部分不是展示态
- 规则级粒度最灵活，不同规则对兜底需求不同（仪表读取可能不需要，渗漏判断需要）
- 结果按正常格式返回+备注标识，保持结果展示统一性，避免"传统算法结果"和"大模型结果"两套展示
- 清单原文"结构化解释/总结/规则引用来源"展示方式取消，过度设计且与兜底语义不符

## 后果

- 检测规则配置表单新增"大模型增强"开关
- 检测规则对象新增大模型增强字段
- 结果页不做改造，备注字段展示"大模型增强"标识
- Mock 服务：规则开启大模型增强且主算法识别失败时，mock 返回兜底结果+备注标识

## 相关

- 取决于：无（检测规则配置现状已具备）
- 影响：模块六第二条工作量从"结果页改造"缩减为"规则表单加开关+mock 兜底"
