# ADR 0019 — 故障接管落调度台可视化、远程校准落控制台配置面板

**状态**：已确认
**日期**：2026-06-23
**关联模块**：7月迭代 模块五（资产管理与维保迁移 — 高可用任务接管 + 远程一键零位校准）

## 背景

清单模块五两条 P2 功能：
1. 故障/低电自动唤醒接管：一号车故障或低电中断时，操作员点【执行无线全量接管】，云端将一号车进度 DAG 断点、离线学习底片、知识库包全量无线铺设至就近空闲二号机器人，实现无感接管续巡。
2. 远程一键零位校准与标定重载：控制台配置面板提供线下更换新激光雷达或云台后的远程一键校准，对齐机械绝对零点与底盘中心轴坐标系，自动重载 SLAM 标定文件及底片库。

现状：两者在 `src/` 零实现。控制台已有配置面板（ConfigPanel.vue/ConfigModal.vue），维保台账在 ADR 0018 补了追踪字段。

## 决策

**接管落调度台、校准落控制台配置面板**。

**接管 mock（调度台）**：
- 调度台监听到一号车故障/低电中断 → 操作员点【执行无线全量接管】按钮
- **可视化展示断点位置**：在调度台地图上标记一号车当前 DAG 断点位置
- **可视化展示迁移过程**：动画/步骤展示"断点提取→知识库包传输→二号车接收→续巡启动"过程
- **迁移记录留痕**：记录接管时间、源机器人、目标机器人、断点位置、迁移数据量、续巡任务 ID
- 二号车从断点续巡，任务不中断

**校准 mock（控制台配置面板）**：
- 控制台配置面板新增"远程一键零位校准"按钮
- 点击后 mock 执行：对齐机械绝对零点与底盘中心轴坐标系→重载 SLAM 标定文件及底片库
- 展示校准进度和结果，校准记录留痕

## 理由

- 接管本质是调度级协调（涉及 DAG 断点迁移和多机器人），与作业票抢占同属调度引擎职责，落调度台符合既有架构
- 校准是单机硬件维护操作，清单明确在控制台配置面板
- 可视化展示断点位置和迁移过程对产品演示价值大，能直观体现"无感接管"卖点
- 迁移记录留痕与 ADR 0007 抢占审计一致，写入 localStorage audit-log（模块一操作审计日志页面不在本次迭代，见 ADR 0023）

## 后果

- 调度台新增【执行无线全量接管】按钮和接管可视化展示（断点位置+迁移过程动画）
- 调度台记录迁移记录
- 控制台配置面板新增【远程一键零位校准】按钮和校准进度展示
- 控制台记录校准记录
- Mock 服务提供接管和校准的 mock 数据流
