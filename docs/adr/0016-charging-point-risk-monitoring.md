# ADR 0016 — 无线充电点风险化监控指标固定外显

**状态**：已确认
**日期**：2026-06-23
**关联模块**：7月迭代 模块四（运行策略与路网底座 — 能源策略对象化/无线充电点风险化监控）

## 背景

清单模块四要求"将无线充电点从普通坐标升格为'巡检/风险辨识对象'。定义并监控充电桩转换效率（80%）、输出功率（1kW）、实际充电功率（800W）等安全指标，非受控即视为隐患"。

现状：导航点已有充电点类型（navType: 'charging'，含 chargingMethod/chargingPower/estimatedChargingTime），但只是静态属性，无监控指标和风险辨识。

## 决策

**充电点升格为"巡检/风险辨识对象"，但不纳入路线编排**——机器人到充电桩充电时顺带监控指标，异常即告警。

**监控指标与阈值固定外显不可配**（类比 ADR 0015 看门狗阈值）：

| 指标 | 阈值 | 说明 |
|---|---|---|
| 转换效率 | ≥80% | 充电桩能量转换效率，低于即隐患 |
| 输出功率 | =1kW | 充电桩额定输出功率，偏差即隐患 |
| 实际充电功率 | =800W | 机器人实际接收充电功率，低于即隐患 |

**mock 方式**：充电点详情页只读展示三个指标当前值和阈值；调度台/控制台机器人充电时 mock 指标数据，超阈值即生成告警走异常处置。

## 理由

- 80%/1kW/800W 是清单明确的工业标准值，类比看门狗阈值逻辑——安全标准值固定不让配但外显，避免误配风险
- 充电点不纳入路线编排：充电是机器人自主行为（低电回充），不是巡检任务的一部分；升格为"巡检对象"的含义是"被监控的对象"而非"被纳入巡检路线的点"
- 路过时顺带监控即可，避免路线编排复杂化

## 后果

- 充电点详情页新增"风险监控指标"区块（只读展示三项指标当前值+阈值）
- 充电点不纳入路线编排，保持 navType=charging 独立
- Mock 服务在机器人充电时生成指标数据，超阈值告警走异常处置
- 异常处置流程新增"充电桩指标异常"告警类型

## 相关

- 取决于：ADR 0002（导航点统一，充电点已属导航点）
- 影响：异常处置流程新增告警类型、充电点详情页扩展
