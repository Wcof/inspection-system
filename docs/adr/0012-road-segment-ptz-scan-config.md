# ADR 0012 — 路段级云台扫描配置归路网管理页

**状态**：已确认
**日期**：2026-06-23
**关联模块**：7月迭代 模块三（边巡边检 — 地图区域风险扫描配置）

## 背景

清单模块三要求"改造边巡边检页，基于 JHA/LEC 风险辨识点，允许实施人员直接在路网地图的某个路段/区域，配置机器人行经该处时的云台持续扫描方位角与高度"。

现状：
- 边巡边检页是只读热力分布查看页（展示历史采样瓦片热力图 + 告警明细），无配置能力
- 云台相关字段散见于"采集姿态"（ptzYaw/ptzPitch/focalLength/method）和"云台预置位"（PTZPreset），均为定点巡检场景
- 路网管理页的路段已承载限速/是否倒车/最大坡度等通行属性

## 决策

**路段级云台扫描配置归路网管理页**（路段编辑内），不进边巡边检页。边巡边检页保持只读查看定位。

**新增路段字段：云台扫描策略**，字段约束如下：

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| 启用扫描 | 布尔 | 默认 false | 是否在该路段启用云台连续扫描 |
| 扫描模式 | 枚举 | `continuous`（连续扫描）/ `sweep`（来回扫）/ `fixed`（锁定方位） | 连续=匀速转一圈；来回扫=在角度区间往返；锁定=固定方位 |
| 方位角起始 | 数字 | 0~360°，默认 0 | 扫描起始方位角（机器人前进方向为 0°，顺时针递增） |
| 方位角结束 | 数字 | 0~360°，默认 360 | 扫描结束方位角（锁定模式下等于起始） |
| 俯仰角 | 数字 | -90~+30°，默认 0 | 云台俯仰角，负值低头、正值抬头；上限 +30° 防止直视天空 |
| 扫描速度 | 数字 | 5~60°/秒，默认 30 | 云台旋转速度 |
| 高度 | 数字 | 0.5~3.0 米，默认 1.5 | 云台安装高度（影响视野覆盖计算） |
| 风险辨识点标识 | 布尔 | 默认 false | 是否标记该路段为 JHA/LEC 风险辨识点（驱动扫描必要性） |
| 关联风险类型 | 枚举数组 | 可多选：泄漏/温升/堆积物/安全行为/气体 | 标识该路段重点识别的风险类型 |

**约束补充**：
- 方位角起始≤结束（除非扫描模式=连续，此时起始=0、结束=360）
- 俯仰角上限 +30° 防止云台对空聚焦（联动清单"云台空旷区避空保护"）
- 扫描速度上限 60°/秒防止抖动影响识别
- 风险辨识点标识=true 时，扫描模式不得为 fixed（必须有扫描动作）

## 理由

- ADR 0001/0002 已确认路网管理页是拓扑属性承载主体，云台扫描配置本质是"机器人行经该路段时的执行策略"，与限速/是否倒车同属路段级属性
- 边巡边检页保持只读查看定位，职责不膨胀
- 现状定点巡检的"采集姿态"字段不动，路段级扫描策略是新增字段，两类场景不混淆
- 字段约束基于物理现实：俯仰角上限防天空聚焦、扫描速度上限防抖动、方位角 0-360 顺时针约定与导航点朝向角一致

## 后果

- 路网管理页的路段编辑表单新增"云台扫描策略"配置区块
- 路段对象新增上述 8 个字段
- 边巡边检页保持只读查看，不变
- 执行端联动（24帧抽帧、避空保护、漫游异常锚定）读取路段扫描策略驱动 mock
