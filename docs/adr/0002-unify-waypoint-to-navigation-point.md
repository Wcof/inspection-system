# ADR 0002 — 巡检点与巡检路线统一引用路网导航点

**状态**：已确认
**日期**：2026-06-23
**关联模块**：7月迭代 模块四 + 路线编辑基础

## 背景

用户明确口径："路网管理先画路网，所有任务/巡检路线必须基于路网"。

现状巡检点和巡检路线引用的是轻量导航点（仅坐标和名称），与路网管理页的导航点（已承载巡检模式/朝向/停留/停车约束/充电点）未打通。原因是任务路线先做、路网后加，mock 数据结构有出入。

路网管理的导航点已是轻量导航点的严格超集，轻量导航点无独立存在价值。

## 决策

合并为一套导航点类型。废弃轻量导航点，巡检点和巡检路线统一引用路网管理的导航点。

## 理由

- 用户口径要求路线必须基于路网，现状未打通是历史遗留
- 路网导航点字段是轻量导航点的超集，合并无信息丢失
- 合并后巡检路线天然变为"路网上的导航点有序序列"，路线与路网打通

## 后果

- 巡检点的"关联导航点"字段改为引用路网管理的导航点
- 巡检路线的"途径点序列"改为路网管理导航点的有序序列
- 计划路线画布页迁移到引用路网
- 迁移期间需处理 mock 数据结构差异
- **影响面（实现阶段需先跑全量引用扫描列清单）**：已知引用点包括巡检点 `waypointId`、巡检路线 `waypointIds`、任务快照 `route.waypointIds`、MockService `getWaypoints()` 等，实现前需全量扫描确认完整迁移清单再动手
