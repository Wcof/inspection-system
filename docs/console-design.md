# 控制台页面设计文档

## 1. 概述

在"总调度台"菜单下新增"控制台"子页面，提供机器人的实时控制和配置管理功能。

**路由：** `/management/dispatch/console`

**菜单位置：** 侧边栏 → 总调度台 → 控制台

---

## 2. 页面结构

### 2.1 顶层 Tab 切换

页面内通过 Tab 切换两个视图：
- **控制** — 机器人实时操控（主功能）
- **配置** — 点位导航与巡检配置

### 2.2 控制页面

#### 2.2.1 布局（全屏沉浸式 HUD）

主画面为 `双目.png`（机器人主行进视角），全屏覆盖，所有信息以 HUD 叠加显示，无固定控制区域。

```
┌─────────────────────────────────────────────┐
│ [机器人▼] [PC/iPad切换]     [开始/暂停/停止] │
│                                              │
│ ┌──────────────────┐          ┌────┬────┐   │
│ │ 机器人信息        │          │可见│热成│   │
│ │ 执行时间: 00:12:34│          │ 光 │ 像 │   │
│ │ 电量: 87%         │          └────┴────┘   │
│ │ 里程: 1.2km       │                        │
│ │ 位置: 点位A-3     │                        │
│ ├──────────────────┤                        │
│ │ 检测数据          │                        │
│ │ 可燃气: 0.02%     │                        │
│ │ O₂: 20.9%        │                        │
│ │ CO: 5ppm          │                        │
│ │ H₂S: 1ppm         │                        │
│ ├──────────────────┤                        │
│ │ 点位信息          │                        │
│ │ 名称: 点位A-3     │                        │
│ │ 装置: 温度传感器   │                        │
│ │ 设施: 阀门组       │                        │
│ │ 对象: 密封面       │                        │

└─────────────────────────────────────────────┘
```

#### 2.2.2 HUD 区域说明

**左上 — 机器人信息：**
- 执行时间：从开始巡检计时，格式 HH:MM:SS
- 电量：百分比，模拟缓慢下降
- 里程：km，模拟缓慢增加
- 位置：当前最近的巡检点位名称

**左中 — 检测数据：**
- 可燃气体（%LEL）
- 氧气（%VOL）
- 一氧化碳（ppm）
- 硫化氢（ppm）
- 不同点位间随机波动模拟

**左下 — 点位信息：**
- 点位名称
- 巡检装置
- 巡检设施设备（无则显示"无"）
- 巡检对象（显示部件名称，无则显示"无"）
- 巡检规则（显示规则，无则显示"无"）
- 机器人到达点位附近时自动切换

**右下 — 速度：**
- 当前移动速度（m/s）
- PC 模式：按 WASD 时变化
- iPad 模式：按方向按钮时变化

**右上 — 摄像头小窗：**
- 上方：可见光（`巡检光学.png`）
- 下方：热成像（`巡检热成.png`）
- 点击可切换为主画面视角，再次点击切回双目

**左下 — 地图缩略图：**
- `缩略地图.png`，半透明叠加
- 点击弹出全屏 modal，显示 `地图.png` 完整地图
- 机器人位置标红，巡检点位标蓝/绿（已校准/未校准）
- 仅查看，不做导航交互

#### 2.2.3 操控模式

**PC 模式（默认）：**
- 底部中央显示半透明键盘提示条
- W：前进 | A：左转 | S：后退 | D：右转 | 空格：刹车
- 按键时速度变化，松开后逐渐减速

**iPad 模式：**
- 右下角显示虚拟方向控制按钮（上/下/左/右 + 刹车）
- 布局类似极品飞车手机版
- 触摸按住持续移动，松开停止

**切换方式：**
- 顶部工具栏提供 "PC/iPad" 切换按钮（原型 mock，不依赖设备检测）

#### 2.2.4 顶部控制栏

| 元素 | 位置 | 说明 |
|------|------|------|
| 机器人选择器 | 左侧 | 下拉框，列出所有机器人，默认选中第一个在线机器人 |
| PC/iPad 切换 | 中间偏左 | 按钮切换操控模式 |
| 任务控制 | 右侧 | 状态 + 开始/暂停/继续/停止 按钮 |

#### 2.2.5 Mock 数据联动

| 数据 | 联动逻辑 |
|------|----------|
| 执行时间 | 开始巡检后持续计时 |
| 电量 | 每秒下降 0.1%（模拟） |
| 里程 | 移动时缓慢增加 |
| 检测数据 | 每 2 秒随机波动 ±5% |
| 点位信息 | 机器人位置与点位距离 < 阈值时自动切换 |
| 速度 | 按控制键时为设定值，松开后归零 |

### 2.3 配置页面

#### 2.3.1 布局

与控制页面相同的全屏布局（主画面 + 地图缩略图 + 摄像头小窗），但：
- 无操控元素（无 WASD/方向按钮、无速度显示）
- HUD 仅显示机器人信息和检测数据
- 点位信息区域变为**可交互的点位列表**

#### 2.3.2 点位列表

HUD 右侧或下方显示当前地图的巡检点位列表：

| 点位名称 | 校准状态 | 操作 |
|----------|----------|------|
| 点位A-1 | ✅ 已校准 | [前往] [变更配置] |
| 点位A-2 | ✅ 已校准 | [前往] [变更配置] |
| 点位A-3 | ⚠️ 未校准 | [前往] [校准] |

- 已校准点位：显示"前往"和"变更配置"按钮
- 未校准点位：显示"前往"和"校准"按钮（无"变更配置"）

#### 2.3.3 点击点位后的信息面板

点击某个点位后，HUD 显示该点位的关联信息：
- 巡检装置
- 巡检设施设备
- 巡检对象
- 巡检规则

#### 2.3.4 "前往"操作

1. 点击"前往"按钮
2. 主画面显示"正在前往点位 X..."提示
3. Mock 倒计时 3 秒
4. 到达后 HUD 更新为该点位信息
5. 到达后可进行校准操作

#### 2.3.5 "校准"操作

1. 点击"校准"按钮
2. 弹出确认弹窗："确认校准该点位？"
3. 确认后：
   - 更新 `point.calibrationStatus` 为 `calibrated`
   - 记录 `point.calibratedAt` 为当前时间
   - 点位列表状态刷新为 ✅ 已校准
   - 显示"校准成功"提示

#### 2.3.6 "变更配置"操作

1. 点击"变更配置"按钮
2. 弹出配置弹窗，包含三个级联下拉框：

```
┌─────────────────────────────────────┐
│ 变更配置 — 点位A-1                  │
│                                      │
│ 巡检装置: [温度传感器      ▼]       │
│                                      │
│ 巡检设施设备: [阀门组        ▼]     │
│                                      │
│ 巡检对象: [密封面            ▼]     │
│                                      │
│        [校准]          [保存]        │
└─────────────────────────────────────┘
```

3. 级联逻辑：
   - 巡检装置：`MockService.getInspectionDevices()` 所有装置
   - 巡检设施设备：根据选中装置过滤 `assetComponents` / `installations`
   - 巡检对象：根据选中设施过滤 `facilityComponents` / `coverageObjects`
4. 底部按钮：
   - "校准"：执行校准操作（同上）
   - "保存"：保存配置，关闭弹窗，刷新配置页面点位列表

## 3. 点位管理页面增强

### 3.1 文件

`src/views/inspection/InspectionPointList.vue`

### 3.2 新增表格列

在现有表格中新增三列（放在"巡检项数量"列之前）：

| 列名 | 字段 | 宽度 | 逻辑 |
|------|------|------|------|
| 巡检装置 | `deviceNames` | 150 | 关联的 `inspectionDevices` 名称，逗号分隔 |
| 巡检设施设备 | `facilityNames` | 150 | 关联的 `coverageObjects` 或 `assetComponents` 名称 |
| 巡检对象 | `objectNames` | 150 | 关联的 component/connection 名称 |

### 3.3 非巡检点处理

判断条件：`point.pointBizType !== 'inspection'`（或使用 `isInspectionBizPoint()` 取反）

非巡检点（充电点、停车点、维修点）的这三列统一显示 `-`。

### 3.4 数据来源

```typescript
// 巡检装置
const deviceNames = inspectionDevices
  .filter(d => d.inspectionPointId === point.id)
  .map(d => d.name)
  .join('、')

// 巡检设施设备
const facilityNames = point.coverageObjects
  ?.filter(o => o.type === 'asset' || o.type === 'component')
  .map(o => o.name)
  .join('、') || '-'

// 巡检对象
const objectNames = point.coverageObjects
  ?.filter(o => o.type === 'component' || o.type === 'connection')
  .map(o => o.name)
  .join('、') || '-'
```

## 5. 交互流程图

### 5.1 控制页面主流程

```
选择机器人 → 选择操控模式(PC/iPad)
         ↓
    开始巡检
         ↓
  ┌──→ 操控移动 ←──────────────────┐
  │      ↓                          │
  │   HUD实时更新                   │
  │   (电量↓ 里程↑ 检测波动)        │
  │      ↓                          │
  │   到达点位？──否──→ 继续操控 ──┘
  │      ↓ 是
  │   显示点位信息
  │      ↓
  │   继续操控 或 停止巡检
  └──────────────────────────────────
```

### 5.2 配置页面主流程

```
查看点位列表
     ↓
点击某个点位
     ↓
显示点位关联信息
     ↓
┌──→ [前往] ──→ 倒计时3秒 ──→ 到达 ──→ [校准]
│                                         ↓
│                                    确认弹窗
│                                         ↓
│                                    校准成功
│                                         ↓
└─────────────────────────────────────────┘

[变更配置] ──→ 配置弹窗
                    ↓
              选择装置 → 设施 → 对象
                    ↓
              [保存] ──→ 刷新页面
```
